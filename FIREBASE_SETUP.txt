FIRESTORE SECURITY RULES
========================

Copy and paste these rules into Firebase Console:

1. Go to: https://console.firebase.google.com
2. Select project: my-darija-companion
3. Click: Firestore Database → Rules tab
4. Replace all text with the rules below
5. Click: Publish

--- RULES START HERE ---

rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    
    // Helper function to check if user is admin
    function isAdmin(auth) {
      return auth != null && 
        get(/databases/$(database)/documents/users/$(auth.uid)).data.isAdmin == true;
    }
    
    // Helper function to check if authenticated
    function isAuthenticated(auth) {
      return auth != null;
    }
    
    // LESSONS - Public read, Admin write
    match /lessons/{lessonId} {
      allow read: if true;
      allow create, update, delete: if isAuthenticated(request.auth) && isAdmin(request.auth);
    }
    
    // VOCABULARY - Public read, Admin write
    match /vocabulary/{vocabId} {
      allow read: if true;
      allow create, update, delete: if isAuthenticated(request.auth) && isAdmin(request.auth);
    }
    
    // QUIZZES - Public read, Admin write
    match /quizzes/{quizId} {
      allow read: if true;
      allow create, update, delete: if isAuthenticated(request.auth) && isAdmin(request.auth);
    }
    
    // USERS - Own read/write, Admin full access
    match /users/{userId} {
      allow read: if isAuthenticated(request.auth) && 
        (request.auth.uid == userId || isAdmin(request.auth));
      allow create: if true;
      allow update: if isAuthenticated(request.auth) && 
        (request.auth.uid == userId || isAdmin(request.auth));
      allow delete: if isAuthenticated(request.auth) && isAdmin(request.auth);
    }
    
    // AUDIT LOGS - Admin only
    match /auditLogs/{logId} {
      allow read, write: if isAuthenticated(request.auth) && isAdmin(request.auth);
    }
    
    // USER QUIZ RESULTS - User own only
    match /users/{userId}/quizResults/{resultId} {
      allow read: if isAuthenticated(request.auth) && 
        (request.auth.uid == userId || isAdmin(request.auth));
      allow create: if isAuthenticated(request.auth) && request.auth.uid == userId;
    }
  }
}

--- RULES END HERE ---

FIREBASE SETUP STEPS
====================

1. Enable Firestore Database
   - Go to Firebase Console
   - Click "Firestore Database"
   - Click "Create database"
   - Choose "Start in production mode"
   - Select location (europe-west for Europe, us-central for US)

2. Upload Security Rules (see above)

3. Set Yourself as Admin:
   - Go to Firestore Database
   - Create collection: "users"
   - Create document with your Firebase Auth UID
   - Add these fields:
     * displayName: "Your Name"
     * email: "your@email.com"
     * isAdmin: true (boolean)
     * level: 1 (number)
     * xp: 0 (number)

4. Enable Authentication:
   - Go to Authentication
   - Click "Get started"
   - Enable "Email/Password" provider
   - Enable "Google" provider (optional)

5. Deploy to Vercel with environment variables
